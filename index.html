Project Details & Architecture

Semester 3 Mini-Project Submission

Project Title:SevaSetu — NGO Volunteer & Donor Portal
Developer:Raghav (Semester 3)
Subject:DBMS / Web Technology Lab Mini-Project
Architecture:Client-Side Single Page Application (Vanilla JS)
Storage:Browser LocalStorage with Relational Foreign Keys

Key Features Implemented:

  • Volunteer Directory: Search by city/skills, status tags, emergency contacts, detailed profile drawers.
  • Donor Roster: Tier tracking (Platinum, Gold, Silver, Bronze), giving history, contact persons.
  • Donation Ledger: 80G tax-exempt receipt generator with printable slips.
  • Community Drives: Capacity tracking (volunteers needed vs deployed), service hours logging.
  • Custom Canvas Charts: Monthly donation trends and category-wise service hours rendered on HTML5 canvas.
  • Data Portability: Export all tables to CSV and download complete JSON database backups.
